## Learning Path

A practical progression is:

1. Begin with **SudoScope** to understand the sudo-focused theme.
2. Continue with **SUID Sleuth** and **SUID Shadows: Corrosion 2** for SUID investigation.
3. Explore **GTFOBins Path to Root** for the GTFOBins-focused challenge.
4. Study **Library Hijack Ladder** for the library-hijacking theme.
5. Move through **Cracked Key Root Shell**, **Unshadowed Secrets**, and **Shadow Siphon** for credential-related challenges.
6. Explore both ZIP labs for archive-focused exercises.
7. Finish with **Reuse Race** and **Tomcat Trails: User Reuse** for credential-reuse concepts.

## How to Use the Labs

1. Open each lab through its direct Learn SecByte link.
2. Review the supplied scope and instructions before starting.
3. Perform all activities only inside authorized lab environments.
4. Record observations, discovered files, permissions, credentials, and security clues.
5. Focus on understanding the underlying security concept.
6. Document lessons learned for future CTF and defensive-security practice.
